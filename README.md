# Nightcall — первая версия голосовых комнат

Тёмный сайт с фиолетовыми акцентами, комнатами по коду/ссылке, загрузкой аватарок, WebRTC-аудио, индивидуальной громкостью участников и выдвижным чатом.

## Запуск локально

Нужен Node.js 18 или новее.

```bash
npm install
npm start
```

Откройте http://localhost:3000. Чтобы проверить голос, откройте сайт в двух разных браузерах/окнах и создайте комнату в одном, затем войдите по коду в другом. Разрешите доступ к микрофону.

## Важно перед публикацией

- Для доступа с других устройств сайт нужно разместить на сервере с HTTPS. Микрофон в браузерах работает только на HTTPS или localhost.
- Для стабильной работы WebRTC через разные сети добавьте TURN-сервер (например, coturn или управляемый TURN-сервис) в `rtcConfig` в `public/app.js`. Сейчас настроены публичные STUN-серверы; некоторые сети не смогут соединиться без TURN.
- Это стартовая версия, рассчитанная на небольшие комнаты (до 12 участников) с mesh WebRTC. Для больших комнат лучше SFU (например, mediasoup/LiveKit).
- Комнаты хранятся в памяти сервера: после перезапуска они исчезают. Для масштабирования используйте Redis/БД и адаптер Socket.IO.
- Выбор устройства вывода через `setSinkId` зависит от браузера. Чат и сигналинг работают через Socket.IO.
- Перед публичным запуском добавьте лимиты запросов, модерацию/жалобы, защиту от злоупотреблений, политику приватности и проверку загрузок.
